## ALTERs e semântica complementar

`surveys` recebe `attendance_date TEXT` opcional e `teams_json TEXT NOT NULL DEFAULT '[]'` na migração de escalas. O domínio de `surveys.shift` passa a incluir `manha`, `tarde` e `noite`, preservando valores legados. FKs e CHECKs compostas aparecem nos blocos SQL acima. RLS é ativada nas tabelas; os grants de runtime são aplicados separadamente. Não são coletados dados clínicos. `created_at` e `updated_at` usam ISO em TEXT; `expires_at` e `until_ms` usam epoch em milissegundos. Não há tabela física de hospitais/tenants: multi-hospital permanece uma expansão proposta.

## Colunas opcionais da revisão do painel

Esses atributos estão em ALTER TABLE no final de `server/schedules-schema.sql`, não no CREATE TABLE inicial. Dados históricos sem metadados permanecem sem classificação. O novo código não exige UPDATE para preencher respostas antigas.
